# 📚 나의 독서 기록장 & 3D 입체 카드 서재

노션 스타일의 독서 노트를 구글 스프레드시트와 연동하고, 모바일에서 한 손으로 기록하며 3D 카드 애니메이션으로 감상할 수 있는 웹앱입니다.

---

## 🌟 주요 기능

1. **✍️ 새 책 기록하기**
   - 장르 선택 (`sf소설`, `에세이`, `소설`, `개발`, `육아` 등) 및 `+ 직접 추가`
   - 책 제목, 작가, 완독일 (기본 오늘)
   - ⭐️ 별점 매기기 (1~5점 터치 선택)
   - 표지 이미지 URL 입력 (비워두면 감성적인 북커버 일러스트 자동 적용)
   - 느낀점 서평 입력 (첫 번째 줄이 카드에 요약되어 노출됩니다)
   - 저장 시 구글 시트에 즉시 기록 ➔ 목록 뷰로 자동 전환되어 방금 추가한 카드 확인!

2. **🎠 기존 독서 목록 보기 (입체 카드 슬라이더 & 그리드)**
   - **3D 카드 슬라이더**: 모바일 터치 스와이프 / 마우스 좌우 드래그 시 카드가 입체적으로 넘어가는 인터랙티브 애니메이션
   - **그리드 모아보기**: 노션 갤러리 뷰처럼 전체 책을 한눈에 볼 수 있는 바둑판 모드 지원
   - 카드 표시 정보: 책 표지, 제목, 작가, 장르 뱃지, 황금 별점, **느낀점 첫 한 줄 평**, 완독 날짜

---

## 🚀 3분 배포 가이드

### 1단계: 스프레드시트에서 Apps Script 열기
1. 독서 기록을 저장할 본인의 구글 스프레드시트를 엽니다. (빈 시트면 첫 실행 때 헤더가 자동 생성됩니다)
2. 주소창 URL에서 `/d/` 와 `/edit` 사이의 문자열이 **스프레드시트 ID**입니다. 복사해 두세요.  
   예: `https://docs.google.com/spreadsheets/d/`**`여기가_ID`**`/edit`
3. 상단 메뉴에서 **[확장 프로그램]** ➔ **[Apps Script]**를 클릭합니다.

---

### 2단계: 코드 붙여넣기 및 저장
1. 편집창에 열려있는 `Code.gs`의 기존 내용을 모두 지웁니다.
2. [`Code.gs`](Code.gs) 코드 전체를 복사하여 붙여넣습니다.
   *(단일 파일 올인원 버전이므로 다른 파일을 만들 필요가 전혀 없습니다)*
3. `Code.gs`에 있는 `YOUR_SPREADSHEET_ID`를 1단계에서 복사한 본인 시트 ID로 모두 바꿉니다.
   (상단 `SPREADSHEET_ID` 상수와 "시트 열기" 링크)
4. 상단의 **💾 저장 (Ctrl+S / Cmd+S)**을 누릅니다.

---

### 3단계: 웹 앱(Web App) 배포
1. 오른쪽 상단 파란색 **[배포]** ➔ **[새 배포]**를 누릅니다.
2. 좌측 톱니바퀴 ⚙️ 아이콘 클릭 ➔ **[웹 앱(Web app)]**을 선택합니다.
3. 다음 옵션을 설정합니다:
   - **설명**: `독서 서재 v1`
   - **다음 사용자 권한으로 실행**: **`나(본인 계정)`**
   - **액세스 권한이 있는 사용자**: **`모든 사용자(Anyone)`** *(로그인 없이 편하게 모바일에서 접속하기 위해 필수!)*
4. 하단 **[배포]** 클릭 ➔ **[액세스 승인]** (경고창 시: 고급 ➔ 안전하지 않음 이동 ➔ 허용)
5. 화면에 나타나는 **첫 번째 [웹 앱 URL]**을 복사합니다.

---

### 🔒 보안 주의사항
- **웹 앱 URL(`https://script.google.com/macros/s/.../exec`)은 비밀번호처럼 다뤄주세요.**  
  '모든 사용자' 권한으로 배포하면 이 URL을 아는 사람은 누구나 내 독서 기록을 **읽고, 새 기록을 추가**할 수 있습니다.
  README, 이슈, 커밋, 공개 채팅방 등에 올리지 마세요.
- URL이 노출됐다면 Apps Script 편집기의 **[배포] ➔ [배포 관리]**에서 해당 배포를 **보관(Archive)**하고 새로 배포하세요. 새 URL이 발급됩니다.
- 이 저장소의 코드에는 스프레드시트 ID 대신 `YOUR_SPREADSHEET_ID`가 들어있습니다. 본인 ID를 넣은 코드는 Apps Script 편집기에만 두고, 다시 커밋하지 마세요.

---

### 📱 4단계: 스마트폰 홈 화면에 추가
복사한 웹 앱 URL을 스마트폰(카카오톡 나와의 채팅 등)으로 보낸 뒤 브라우저에서 열고:
- **아이폰 (Safari)**: 하단 가운데 [공유] ➔ **[홈 화면에 추가]**
- **갤럭시 (Chrome)**: 우측 상단 [점 3개 ⋮] ➔ **[홈 화면에 추가]**
- 이제 바탕화면에서 나만의 예쁜 독서 서재 앱을 바로 실행할 수 있습니다! 🎉
